Bildgröße ändern

Ist es wirklich kostenlos?

Ja. Es gibt keine Anmeldung, keine Testphase und kein Tageslimit. Die Seite wird durch eine einzelne Werbeanzeige neben dem Tool finanziert. Sehr große Bilder können für ein Smartphone oder einen alten Computer zu viel sein. Dann sehen Sie eine Meldung.

Werden meine Bilder hochgeladen?

Nein. Die Größenänderung findet auf Ihrem eigenen Gerät in Ihrem Browser statt. Ihre Bilder werden nie an unsere Server gesendet.

Welche Formate werden unterstützt?

Sie können JPG-, PNG-, WebP-, GIF- und BMP-Dateien öffnen, und AVIF, sofern Ihr Browser es unterstützt. Gespeichert werden kann als JPG, PNG oder WebP.

Verringert die Größenänderung die Qualität?

Ein verkleinertes Bild bleibt scharf, weil das Tool einen hochwertigen Filter verwendet. Beim Vergrößern können keine Details entstehen, die nicht vorhanden sind, daher wirken vergrößerte Bilder weicher. Bei JPG und WebP können Sie die Qualität selbst wählen.

Wie bekomme ich ein Bild unter eine Größe wie 50 KB?

Aktivieren Sie „Dateigröße begrenzen“, geben Sie die Zahl ein und klicken Sie auf „Größe ändern“. Das Tool senkt die Qualität und bei Bedarf die Abmessungen, bis die Datei passt. Wählen Sie JPG oder WebP für die besten Ergebnisse, denn PNG lässt sich so nicht verkleinern.

Funktioniert es auf meinem Smartphone?

Ja. Die Seite funktioniert in aktuellen Versionen von Chrome, Safari, Firefox und Edge auf Smartphones, Tablets und Computern. Sehr große Fotos können auf älteren Smartphones an Grenzen stoßen.

Auf KB verkleinern

Warum ist meine Datei immer noch größer als das Limit?

Sehr detailreiche Fotos brauchen mehr Daten. Wenn das Limit selbst bei der niedrigsten Qualität nicht erreicht wird, verkleinert das Tool zusätzlich das Bild. Wird das Ziel trotzdem nicht erreicht, teilt es Ihnen die kleinstmögliche Größe mit.

Kann ich viele Fotos auf dasselbe Limit verkleinern?

Ja. Fügen Sie alle hinzu, legen Sie das Limit einmal fest und laden Sie sie zusammen als ZIP-Datei herunter.

Wird mein Foto auf einen Server hochgeladen?

Nein. Alles geschieht in Ihrem Browser, daher verlässt Ihr Foto nie Ihr Gerät.

Größe in cm, mm oder Zoll

Wie viele Pixel hat ein Zoll?

Das hängt von den DPI ab. Bei 300 DPI sind es 300 Pixel pro Zoll. Bei 96 DPI sind es 96 Pixel.

Wird es genau in dieser Größe gedruckt?

Das Tool legt die Pixelgröße fest, die Ihrer Größe bei den gewählten DPI entspricht. Drucken Sie das Bild in tatsächlicher Größe oder mit diesen DPI, um die gewünschte Größe zu erhalten.

Wie groß ist ein Foto im Format 4 x 6 Zoll?

Bei 300 DPI sind 4 x 6 Zoll 1.200 x 1.800 Pixel.

Passfoto-Größe

Welche Größe hat ein Standard-Passfoto?

Das ist unterschiedlich. Die USA verwenden 2 x 2 Zoll (51 x 51 mm). Das Vereinigte Königreich, die Europäische Union und Australien verwenden 35 x 45 mm. Kanada verwendet 50 x 70 mm.

Kann ich das für ein Visumfoto verwenden?

Ja, wenn die Visumvorgabe einer dieser Größen entspricht. Viele Visa verwenden dieselbe Größe wie der Reisepass, manche Länder haben aber eigene Vorgaben. Prüfen Sie deshalb immer die offiziellen Regeln.

Wie viele Pixel hat ein Passfoto?

Bei 300 DPI sind 35 x 45 mm 413 x 531 Pixel und 2 x 2 Zoll 600 x 600 Pixel.

Größen für soziale Medien

Welche Größe ist für einen Instagram-Beitrag am besten?

Verwenden Sie 1080 x 1080 Pixel für einen quadratischen Beitrag und 1080 x 1350 Pixel für einen Beitrag im Hochformat.

Welche Größe sollte ein YouTube-Vorschaubild haben?

1280 x 720 Pixel, mit einer Dateigröße unter 2 MB.

Wird mein Bild zugeschnitten?

Bei „Rahmen füllen und zuschneiden“ bleibt die Bildmitte erhalten, und die Ränder, die nicht passen, werden abgeschnitten. Wählen Sie „In den Rahmen einpassen“, wenn Sie alles behalten möchten.

Bilder konvertieren

Verringert das Konvertieren die Qualität?

Die PNG-Ausgabe ist verlustfrei. JPG und WebP sind verlustbehaftet, aber bei hoher Qualität ist der Unterschied kaum zu sehen. Sie können die Qualität selbst einstellen.

Kann ich HEIC-Fotos von meinem iPhone konvertieren?

Noch nicht, da die meisten Browser HEIC-Dateien nicht öffnen können. Auf Ihrem iPhone können Sie die Kameraformate auf „Maximale Kompatibilität“ stellen oder das Foto als JPG teilen.

Bilder komprimieren

Wie viel kleiner wird meine Datei?

Fotos direkt vom Smartphone schrumpfen oft um 60 bis 90 Prozent. Bereits komprimierte Bilder werden weniger kleiner.

Kann ich viele Bilder gleichzeitig komprimieren?

Ja. Fügen Sie alle hinzu und laden Sie eine einzige ZIP-Datei herunter.

Auf 20 KB verkleinern

Wie verkleinere ich ein Foto auf 20 KB?

Fügen Sie das Foto hinzu, lassen Sie das Limit von 20 KB ausgewählt und klicken Sie auf „Größe ändern“. Das Tool sucht die höchste JPG-Qualität, die unter 20 KB passt, und verkleinert das Bild nur, wenn das nicht genügt.

Sind 20 KB dasselbe wie 20.000 Byte?

Hier schon. Manche Systeme zählen 1 KB als 1.024 Byte, daher liegt eine Datei unter 20.000 Byte in beiden Fällen unter dem Limit.

Kann ich das für eine Unterschrift verwenden?

Ja. Unterschreiben Sie mit einem dunklen Stift auf weißem Papier, fotografieren Sie die Unterschrift bei gutem Licht, schneiden Sie eng zu und verkleinern Sie sie auf 20 KB. Für Unterschriften gibt es außerdem eine eigene Seite.

Wird mein Foto hochgeladen?

Nein. Alles geschieht in Ihrem Browser, daher bleibt das Bild auf Ihrem Gerät.

Auf 50 KB verkleinern

Wie komprimiere ich ein Foto auf 50 KB ohne Qualitätsverlust?

Alle Details lassen sich nicht erhalten, die sichtbare Qualität aber schon. Das Tool senkt zuerst schrittweise die JPG-Qualität und verkleinert erst danach das Bild, sodass Sie das schärfste Ergebnis bekommen, das passt.

Welches Format sollte ich für ein Foto mit 50 KB verwenden?

JPG. Es liefert die kleinsten Dateien für Fotos und wird von fast jedem Portal akzeptiert.

Ist das Foto genau 50 KB groß?

Es ist 50 KB groß oder kleiner. Das Tool zielt knapp unter das Limit, damit die Datei auf jedem System durchgeht.

Speichern Sie mein Foto?

Nein. Das Bild wird auf Ihrem Gerät verarbeitet und nie hochgeladen.

Auf 100 KB verkleinern

Wie komprimiere ich ein Bild auf 100 KB?

Fügen Sie das Bild hinzu, lassen Sie das Limit von 100 KB ausgewählt und klicken Sie auf „Größe ändern“. Das Tool findet die beste JPG-Qualität, die passt.

Kann ich hier ein PDF auf 100 KB komprimieren?

Nein. Dieses Tool arbeitet mit Bildern (JPG, PNG, WebP, GIF und BMP). Speichern oder fotografieren Sie die Seite zuerst als Bild.

Ist die Qualität bei 100 KB gut?

Für Fotos von Gesichtern und für Dokumente meist ja. Sehr detailreiche Bilder, etwa große Landschaften, wirken eventuell weicher.

Ist es kostenlos und privat?

Ja. Es gibt keine Anmeldung und kein Wasserzeichen, und Ihre Dateien verlassen nie Ihr Gerät.

Auf 200 KB verkleinern

Wie verkleinere ich ein Bild auf 200 KB?

Fügen Sie das Bild hinzu, lassen Sie das Limit von 200 KB ausgewählt und klicken Sie auf „Größe ändern“. Das Tool wählt die beste JPG-Qualität, die passt.

Was ist der Unterschied zwischen 200 KB und 2 MB?

2 MB sind etwa zehnmal so viel. 200 KB sind nur 0,2 MB. Prüfen Sie, ob die Einheit in Ihrem Formular KB und nicht MB lautet.

Kann ich PNG für ein Limit von 200 KB verwenden?

PNG-Dateien sind verlustfrei, daher kann das Tool das Bild nur verkleinern, um ein Limit zu erreichen. JPG behält bei gleicher Dateigröße mehr Details.

Sind meine Dokumente sicher?

Ja. Sie werden in Ihrem Browser verarbeitet und nie hochgeladen, was bei Ausweisdokumenten wichtig ist.

Unterschrift verkleinern

Welche Größe sollte eine Unterschrift für ein Online-Formular haben?

Das hängt vom Formular ab. Viele verlangen etwa 10 bis 20 KB und eine kleine Breite und Höhe in Pixeln. Halten Sie sich immer an die genauen Zahlen in der offiziellen Mitteilung.

Wie bringe ich meine Unterschrift auf 10 KB?

Fügen Sie die Unterschrift hinzu, wählen Sie in der Vorlagenliste das Limit von 10 KB und klicken Sie auf „Größe ändern“.

Kann ich den Papierhintergrund entfernen?

Dieses Tool ändert die Größe und komprimiert; es entfernt keine Hintergründe. Verwenden Sie einfaches weißes Papier, damit das Ergebnis sauber aussieht.

Ist es sicher, hier meine Unterschrift zu verwenden?

Es wird nichts hochgeladen. Die Unterschrift wird in Ihrem Browser verarbeitet und bleibt auf Ihrem Gerät.

PNG in JPG umwandeln

Wie wandle ich PNG in JPG um?

Fügen Sie Ihr PNG hinzu, achten Sie darauf, dass JPG das Ausgabeformat ist, und klicken Sie auf „Größe ändern“. Laden Sie das JPG herunter, sobald es fertig ist.

Verringert die Umwandlung von PNG in JPG die Qualität?

Ein wenig. JPG ist verlustbehaftet. Bei einer Qualität von 85 oder höher ist der Unterschied bei Fotos kaum zu sehen.

Was passiert mit transparenten Bereichen?

Sie werden mit Weiß gefüllt, weil JPG nicht transparent sein kann.

Kann ich viele PNG-Dateien gleichzeitig umwandeln?

Ja. Fügen Sie beliebig viele hinzu, bis zu 500 auf einmal, und laden Sie sie einzeln oder als ZIP herunter.

JPG in PNG umwandeln

Wie wandle ich JPG in PNG um?

Fügen Sie Ihr JPG hinzu, achten Sie darauf, dass PNG das Ausgabeformat ist, und klicken Sie auf „Größe ändern“. Laden Sie das PNG herunter, sobald es fertig ist.

Ist das PNG größer als das JPG?

Meist ja, bei Fotos oft um ein Vielfaches, weil PNG jedes Detail behält.

Verbessert die Umwandlung von JPG in PNG die Qualität?

Nein. Sie verhindert weiteren Qualitätsverlust, kann aber keine Details zurückbringen, die die JPG-Komprimierung bereits entfernt hat.

Werden meine Dateien hochgeladen?

Nein. Die Umwandlung läuft in Ihrem Browser, und Ihre Bilder verlassen nie Ihr Gerät.

WebP in JPG umwandeln

Kann ich WebP auf meinem Smartphone in JPG umwandeln?

Ja. Es funktioniert im Browser jedes aktuellen Smartphones, ohne dass Sie eine App installieren müssen.

Warum speichern Websites Bilder als WebP?

WebP-Dateien sind bei ähnlicher Qualität kleiner als JPG-Dateien, wodurch Seiten schneller laden.

Ist die Qualität nach der Umwandlung gleich?

Fast. Beide Formate sind verlustbehaftet, daher sieht das Bild bei hoher JPG-Qualität gleich aus.

Ist es kostenlos?

Ja. Es gibt keine Anmeldung, kein Wasserzeichen und keine Begrenzung der Bildanzahl.
