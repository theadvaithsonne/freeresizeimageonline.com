画像リサイズ

本当に無料ですか？

はい。登録も、お試し期間も、1日の利用制限もありません。サイトの運営費は、ツールの横に表示される広告1つでまかなっています。とても大きな画像は、スマートフォンや古いパソコンには負担が大きすぎる場合があります。その際はメッセージが表示されます。

画像はアップロードされますか？

いいえ。リサイズはお使いの端末の中、ブラウザ内で行われます。画像が当社のサーバーに送られることはありません。

どの形式に対応していますか？

JPG、PNG、WebP、GIF、BMPのファイルを開けます。ブラウザが対応していればAVIFも開けます。保存形式はJPG、PNG、WebPから選べます。

リサイズすると画質は落ちますか？

高品質なフィルターを使っているので、小さくしても鮮明さは保たれます。大きくする場合は、元にない細かい部分を足すことはできないため、少しぼやけて見えます。JPGとWebPでは画質を自分で選べます。

50 KBなどのサイズ以下にするにはどうすればいいですか？

「ファイルサイズを制限」をオンにして数字を入力し、「リサイズ」を押してください。ファイルが収まるまで、画質を下げ、必要に応じてサイズも小さくします。PNGはこの方法では小さくできないので、JPGまたはWebPがおすすめです。

スマートフォンでも使えますか？

はい。スマートフォン、タブレット、パソコンの最新版のChrome、Safari、Firefox、Edgeで動作します。古いスマートフォンでは、とても大きな写真は処理できない場合があります。

KB指定でリサイズ

なぜファイルが上限より大きいままなのですか？

細かい部分の多い写真は、より多くのデータが必要になります。最低の画質でも上限に収まらない場合は、画像そのものも小さくします。それでも目標に届かないときは、作れる最小のサイズをお知らせします。

たくさんの写真を同じ上限でリサイズできますか？

はい。すべて追加して上限を一度設定すれば、ZIPファイルにまとめてダウンロードできます。

写真はサーバーにアップロードされますか？

いいえ。すべてブラウザの中で処理されるので、写真が端末の外に出ることはありません。

cm・mm・インチでリサイズ

1インチは何ピクセルですか？

DPIによって変わります。300 DPIなら1インチは300ピクセル、96 DPIなら96ピクセルです。

ぴったりこのサイズで印刷できますか？

このツールは、選んだDPIでそのサイズになるピクセル数を設定します。指定したサイズで印刷するには、画像を実寸、または同じDPIで印刷してください。

4 x 6インチの写真は何ピクセルですか？

300 DPIでは、4 x 6インチは1,200 x 1,800ピクセルです。

パスポート写真のサイズ

パスポート写真の標準サイズは何ですか？

国によって異なります。アメリカは2 x 2インチ（51 x 51 mm）、イギリス、EU、オーストラリアは35 x 45 mm、カナダは50 x 70 mmです。

ビザ用の写真にも使えますか？

ビザの規定がいずれかのサイズに合っていれば使えます。多くのビザはパスポートと同じサイズですが、独自のサイズを定めている国もあるため、必ず公式の規定をご確認ください。

パスポート写真は何ピクセルですか？

300 DPIでは、35 x 45 mmは413 x 531ピクセル、2 x 2インチは600 x 600ピクセルです。

SNS画像のサイズ

Instagramの投稿に最適なサイズは？

正方形の投稿は1080 x 1080ピクセル、縦長の投稿は1080 x 1350ピクセルです。

YouTubeのサムネイルは何サイズにすればいいですか？

1280 x 720ピクセルで、ファイルサイズは2 MB未満です。

画像は切り抜かれますか？

「枠いっぱいに切り抜く」では、画像の中央が残り、収まらない端の部分が切り取られます。すべてを残したいときは、「枠に収める」を選んでください。

画像を変換

変換すると画質は落ちますか？

PNGでの出力は可逆圧縮です。JPGとWebPは非可逆圧縮ですが、高画質に設定すれば違いはほとんどわかりません。画質は自分で設定できます。

iPhoneのHEIC写真を変換できますか？

今のところできません。ほとんどのブラウザはHEICファイルを開けないためです。iPhoneでは、カメラの形式を「互換性優先」に設定するか、写真をJPGで共有してください。

画像を圧縮

ファイルはどのくらい小さくなりますか？

スマートフォンで撮ったままの写真は、60～90%小さくなることがよくあります。すでに圧縮されている画像は、それほど小さくなりません。

たくさんの画像をまとめて圧縮できますか？

はい。すべて追加して、ZIPファイル1つでダウンロードできます。

画像を20KBにリサイズ

写真を20 KBにするにはどうすればいいですか？

写真を追加し、20 KBの上限を選んだまま「リサイズ」を押します。ツールは20 KBに収まる最も高いJPGの画質を探し、それでも足りないときだけ画像を小さくします。

20 KBは20,000バイトのことですか？

このツールではそうです。1 KBを1,024バイトで数えるシステムもありますが、20,000バイト未満のファイルなら、どちらの数え方でも上限内に収まります。

署名にも使えますか？

はい。濃い色のペンで白い紙に署名し、明るい場所で撮影して、署名のすぐ近くまで切り抜き、20 KBにリサイズします。署名のリサイズ専用のページもあります。

写真はアップロードされますか？

いいえ。すべてブラウザの中で処理されるので、画像は端末の外に出ません。

画像を50KBにリサイズ

画質を落とさずに写真を50 KBに圧縮するにはどうすればいいですか？

すべての細部を残すことはできませんが、見た目の画質は保てます。ツールはまずJPGの画質を少しずつ下げ、そのあとで初めて画像のサイズを小さくするので、収まる中で最もくっきりした結果になります。

50 KBの写真には、どの形式を使えばいいですか？

JPGです。写真ではいちばん小さいファイルになり、ほとんどのサイトで受け付けられます。

ちょうど50 KBになりますか？

50 KB以下になります。どのシステムでも通るよう、ツールは上限のすぐ手前を狙います。

写真は保存されますか？

いいえ。画像は端末の中で処理され、アップロードされることはありません。

画像を100KBにリサイズ

画像を100 KBに圧縮するにはどうすればいいですか？

画像を追加し、100 KBの上限のまま「リサイズ」を押します。ツールが収まる中で最良のJPGの画質を見つけます。

ここでPDFを100 KBに圧縮できますか？

いいえ。このツールが扱うのは画像（JPG、PNG、WebP、GIF、BMP）です。先にそのページを画像として保存するか、撮影してください。

100 KBで画質は十分ですか？

顔写真や書類なら、たいてい十分です。大きな風景写真のように細部の多い画像は、やや柔らかく見えることがあります。

無料で、プライバシーも守られますか？

はい。登録も透かしもなく、ファイルが端末の外に出ることはありません。

画像を200KBにリサイズ

画像を200 KBに縮小するにはどうすればいいですか？

画像を追加し、200 KBの上限のまま「リサイズ」を押します。ツールが収まる中で最良のJPGの画質を選びます。

200 KBと2 MBはどう違いますか？

2 MBは約10倍の大きさです。200 KBは0.2 MBしかありません。フォームの単位がMBではなくKBであることを確認してください。

200 KBの上限にPNGを使えますか？

PNGは可逆圧縮のため、上限に合わせるには画像そのものを小さくするしかありません。同じファイルサイズなら、JPGのほうが細部を多く残せます。

書類は安全ですか？

はい。ブラウザの中で処理され、アップロードされることはありません。身分証明書類では特に大切なことです。

署名画像をリサイズ

オンラインフォームの署名は、どのくらいのサイズにすればいいですか？

フォームによって異なります。10～20 KB程度で、幅と高さが小さなピクセルサイズに指定されることが多いです。必ず公式の案内にある数値に従ってください。

署名を10 KBにするにはどうすればいいですか？

署名を追加し、「プリセット」の一覧で10 KBの上限を選んで、「リサイズ」を押します。

紙の背景を消せますか？

このツールが行うのはリサイズと圧縮で、背景の削除はできません。仕上がりがきれいになるよう、無地の白い紙を使ってください。

ここで署名を使っても安全ですか？

何もアップロードされません。署名はブラウザの中で処理され、端末の外に出ません。

PNGをJPGに変換

PNGをJPGに変換するにはどうすればいいですか？

PNGを追加し、出力形式がJPGになっていることを確認して「リサイズ」を押します。準備ができたらJPGをダウンロードします。

PNGをJPGに変換すると画質は落ちますか？

少しだけ落ちます。JPGは非可逆圧縮だからです。画質85以上なら、写真では違いがほとんどわかりません。

透明な部分はどうなりますか？

JPGは透明にできないため、白で塗りつぶされます。

たくさんのPNGファイルを一度に変換できますか？

はい。一度に最大500枚まで、好きなだけ追加でき、1枚ずつ、またはZIPでダウンロードできます。

JPGをPNGに変換

JPGをPNGに変換するにはどうすればいいですか？

JPGを追加し、出力形式がPNGになっていることを確認して「リサイズ」を押します。準備ができたらPNGをダウンロードします。

PNGはJPGより大きくなりますか？

たいていは大きくなります。PNGはすべての細部を残すので、写真では数倍になることもよくあります。

JPGをPNGに変換すると画質は良くなりますか？

いいえ。これ以上の劣化は防げますが、JPGの圧縮ですでに失われた細部は元に戻せません。

ファイルはアップロードされますか？

いいえ。変換はブラウザの中で行われ、画像が端末の外に出ることはありません。

WebPをJPGに変換

スマートフォンでWebPをJPGに変換できますか？

はい。最近のスマートフォンのブラウザならどれでも使え、アプリのインストールは不要です。

なぜウェブサイトは画像をWebPで保存するのですか？

同じ画質なら、WebPのほうがJPGよりファイルが小さく、ページの表示が速くなるからです。

変換しても画質は同じですか？

ほぼ同じです。どちらの形式も非可逆圧縮なので、JPGの画質を高くすれば、見た目はそのまま保てます。

無料ですか？

はい。登録も透かしもなく、画像の枚数にも制限はありません。
