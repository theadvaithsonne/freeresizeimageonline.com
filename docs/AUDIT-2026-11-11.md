# Independent audit - 2026-11-11

An independent reviewer went through the live site (tool, layout on 8 screen sizes, 5 languages, accessibility,
SEO, AdSense policy, code) and listed 50 findings. This file records what was done about each one.

Status words: **Fixed** = changed in the code and checked. **You** = only the site owner can do it (accounts and dashboards).
**After approval** = needs real ad units first.

| # | Finding | Status | What was done |
|---|---|---|---|
| F-01 | High - Result rows collapse to ~0 px wide on laptops and tablets in landscape | Fixed | Results moved to their own view with cards (no more narrow rows). |
| F-02 | High - Auto ads are very likely ON in the AdSense account (conflicts with "Auto ads OFF") | You | Turn Auto ads OFF in AdSense (Sites > freeresizeimageonline.com > Auto ads). |
